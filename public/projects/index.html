ViBot

Discord Bot · Spring 2020 - Spring 2024 · ViBot (Startup)

ViBot is a comprehensive Discord bot for managing community organization and moderation in 'Realm of the Mad God'. Features include user authentication, moderation, and a REST API for external web app interaction. ViBot also includes a basic machine learning model for user account detection (alternate vs. main) and utilizes NLP and web scraping for dynamic data gathering. The project emphasizes skills in real-time analytics, cloud deployment, and backend integration with Google Cloud and AWS.

ViBot.tech

Web App · Fall 2020 · ViBot (Startup)

A web-based interface for interacting with the ViBot project, showcasing data visualization and real-time server management. Recycling Classification

Webapp + Machine Learning Model · Spring 2021 · University of North Carolina at Charlotte

A computer vision application for recycling classification based on image/video input, built using PyTorch and FastAI. The project utilizes image processing and data augmentation techniques to improve classification accuracy. Hosted on Google Firebase with a frontend in React.js, it integrates deep learning and web app deployment, demonstrating proficiency in applied AI, sustainability tech, and image recognition solutions.

C-Track

Asset Tracking Webapp · Summer 2021 - Fall 2022 · MDCentric

C-Track is a real-time asset tracking system designed for internal use at MDCentric. Built with React.js and Express, it uses MS SQL Server for data storage and Microsoft OAuth for authentication. Features include user permissions management, customizable attributes, and enterprise-level data security. This project highlights skills in enterprise application development, real-time data handling, and secure authentication solutions.
